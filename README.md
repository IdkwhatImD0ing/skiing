# Skiing

Repo for planning and pitching ski trips to friends. Bay Area (San Jose) based, Tahoe focused.

## The benchmark

Every trip gets measured against the same yardstick:

> **$60/day on lift** — a 4-pack for ~$240 — with rentals either on site or picked up in San Jose.

That's the Boreal baseline. A proposal is worth making if it beats that on price, or clearly justifies costing more (better terrain, better for the group, shorter drive).

## Layout

```
proposals/    one file per trip pitch — TEMPLATE.md to start a new one
research/     resort pricing, deals, rentals, logistics (dated, sourced)
```

## How to use it

1. Copy `proposals/TEMPLATE.md` to `proposals/<resort>-<date>.md`.
2. Fill the cost table — per person, all in: lift, rental, lodging, gas, food.
3. Check `research/` for current prices before quoting any number.
4. Track headcount and who's paid in the table at the bottom.

## Ground rules for research files

- Every price carries a **source URL** and the **season it applies to**.
- Last season's price is labeled as last season's, never passed off as current.
- Purchase deadlines and price-step dates go at the top — that's where money is won or lost.
- Re-check prices before committing money. Ski pricing moves.
